# الإعداد والتشغيل

## الطريقة الأسهل

اتبع START-HERE.md وشغّل START-WINDOWS.cmd ثم افتح رابط localhost. معالج setup.php ينشئ الجداول و15 منتجًا وأدمنًا تختار بياناته، ويرفض قاعدة تحتوي جداول بدل حذفها. يتطلب تشغيل PHP وMySQL فعليًا.

اختُبر المشروع على PHP 8.4.27 وMySQL 8.0.45. يتطلب PHP 8.2+ وPDO MySQL وmbstring وOpenSSL وArgon2id. XAMPP قد يحتوي MariaDB؛ مرجع هذه النسخة هو MySQL الفعلي.

## الاستيراد اليدوي البديل

اختر طريقة واحدة فقط؛ لا تستورد SQL ثم تحاول معالج الإعداد على نفس القاعدة.

1. أنشئ قاعدة MySQL فارغة باسم تختاره.
2. استورد database/stor.sql فيها. الملف يحتوي 23 جدولًا و3 views و15 منتجًا، ولا يحوي حسابات أو كلمات مرور.
3. من جذر المشروع نفّذ `php scripts/config-init.php`.
4. افتح config/config.local.php وضع اتصال القاعدة واضبط origin على http://127.0.0.1:8088. أضف أي عنوان محلي آخر تفتح منه الموقع (مثل http://stor-html-php.test في Laragon) إلى allowed_origins، وإلا تُرفض طلبات الدخول والطلب برمز 403. احتفظ بمفتاح التشفير الذي ولّده السكربت.
5. نفّذ `php scripts/create-admin.php` وأنشئ حسابك.
6. شغّل `php -S 127.0.0.1:8088 -t public router.php`.

إذا استعملت database/00-create-database.example.sql، بدّل كلمات المرور المثاليتين محليًا أولًا. استخدم حساب التهيئة للجداول ثم حساب التشغيل للاستعمال اليومي. لا تستخدم قاعدة Node.js القديمة؛ هذه نسخة منفصلة وصيغة كلمات مرورها PHP Argon2id.

## البريد

داخل config/config.local.php املأ smtp. لـGmail: host=smtp.gmail.com، port=587، secure=false، user بريد المرسل، password كلمة مرور تطبيق Google، وfrom_email نفس البريد. لا ترسل كلمات المرور في الدردشة أو تضعها في public.

نسخة التسليم لا تتضمن عامل إرسال البريد: تُحفظ الرسائل (الفواتير وتحديثات الحالة) في جدول email_outbox وتظهر في لوحة الإدارة، ولا يدعي الموقع إرسالها. الفاتورة المرفقة HTML قابلة للطباعة والحفظ PDF من المتصفح.

لمزود MySQL يستخدم TLS، ضع المسار المطلق لشهادة CA في db.ssl_ca. احتفظ بالتحقق من الشهادة.

## الاستضافة

استعمل استضافة تدعم PHP/MySQL، وجذر الموقع public فقط. المجلدات app/config/database/scripts/vendor ليست للتصفح العام. ملفات api.php المباشرة تعمل دون mod_rewrite. الموقع السابق في Netlify لا يشغّل PHP؛ هذه النسخة لا تغيّره تلقائيًا.

## تشخيص سريع

- PHP not found: ثبّت PHP أو استعمل مساره الكامل.
- Access denied: بيانات مستخدم MySQL أو صلاحياته غير مطابقة.
- could not find driver: فعّل pdo_mysql في php.ini.
- undefined mb_strlen: فعّل mbstring.
- أصل الطلب غير مسموح: origin لا يطابق عنوان المتصفح والمنفذ.
- صفحة HTML تظهر رسالة إعداد: شغّل PHP بدل Live Server وأكمل setup.php.
- database contains tables: اختر قاعدة فارغة؛ لا تحذف قاعدة فيها بيانات لتجاوز الرسالة.
- إذا تعطّل استيراد DDL جزئيًا، لا تعِد التنفيذ فوق الجداول دون مراجعة الخطأ. استعمل قاعدة جديدة فارغة أو أصلح الحالة يدويًا.
