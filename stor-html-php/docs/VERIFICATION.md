# نتائج التحقق من النسخة المصححة

تاريخ الاختبار: 27 أكتوبر 2026.

- 20 صفحة HTML مستقلة ذات محتوى فعلي وكود مقروء؛ CSS وJavaScript في ملفات مستقلة.
- فحص الروابط والموارد المحلية: نجح، مع 11 صورة وجدولين ووسائط صوتية.
- جميع ملفات PHP الخاصة بالتطبيق اجتازت فحص الصياغة، وجميع ملفات JavaScript اجتازت فحص الصياغة.
- اختبار المتصفح: 21 صفحة تشمل الإدارة × 4 عروض (1440، 768، 390، 320) = 84 حالة؛ دون تجاوز أفقي أو رسالة فشل اتصال أثناء الفحص.
- جرى تنفيذ تسجيل عميل، اختيار لون ومقاس، إضافة للسلة، إتمام طلب وفتح فاتورته من المتصفح.
- جرى دخول الأدمن وإضافة منتج وتعديل سعره والبحث عنه في جدول PHP؛ عولج تحديث الجدول مع الحفاظ على حقل البحث.
- اختبارات API: 17 سيناريو ناجح تشمل CRUD، حفظ الحساب، CSRF، فصل صلاحيات الأدمن والعميل، ملكية الفواتير، المخزون ومنع تكرار الطلب.
- اختبارات النطاق: 10 حالات ناجحة تشمل إعادة التعيين وإلغاء الطلب وإرجاع المخزون.
- البريد: اختبار PHPMailer عبر STARTTLS مع خادم التقاط محلي؛ 4 رسائل دون إرسال بريد خارجي.
- الحزمة: فحص سلامة ZIP ثم فكها في مجلد جديد وتشغيلها على المنفذ 8091 وقاعدة MySQL فارغة؛ نجح الإعداد الأول وإنشاء الأدمن وإغلاق صفحة الإعداد، ثم نجحت السيناريوهات الـ17 على الملفات المستخرجة نفسها.

ملفات النتائج التفصيلية بجوار هذا الملف. لا تتضمن الحزمة بيانات اتصال محلية أو حساب أدمن جاهزًا. تحتاج تشغيل PHP وMySQL وإكمال شاشة الإعداد. اختبار البريد المحلي لا يعني إعداد مزود بريد حقيقي؛ يلزم إعداد SMTP لذلك.
