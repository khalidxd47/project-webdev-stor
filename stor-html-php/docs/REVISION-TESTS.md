# اختبارات تحديث اللغة والتحميل والتنقل

27 أكتوبر 2026 — PHP 8.4.27 وقاعدة MySQL محلية للاختبار، دون تعديل الموقع المنشور.

- اختبار فعلي للصفحات العشرين بالإنجليزية على أربعة عروض: 1440 و768 و390 و320 = 80 حالة، دون تجاوز أفقي أو خطأ تحميل.
- اختبار الصفحات العشرين بالعربية على 390 بكسل = 20 حالة ناجحة.
- اكتُشف تجاوز رأس الصفحة الإنجليزية على التابلت وأُصلح ثم أُعيدت الفحوص بنجاح.
- فتح الطلبات والتتبع والفاتورة من المتصفح مع جلسة عميل فعلية؛ بيانات الطلب والإجماليات ظهرت.
- تأكيد لون الرابط النشط لطلباتي: rgb(111, 170, 255) في قائمتي الجوال والدسكتوب.
- تغيير لون تيشيرت مطبوع واختيار M وإضافته للسلة؛ ظهرت الطباعة واللون والمقاس في السلة.
- تبديل اللغة أثناء تعبئة نموذج الملف الشخصي لم يُفقد النص المكتوب.
- التنقل بين ستة تبويبات إدارية بسرعة؛ التبويب النهائي عرض بياناته دون رسالة خطأ أو خطأ JavaScript مسجل.
- 17 سيناريو API ناجح: التسجيل والدخول والصلاحيات وCRUD والمخزون والطلبات والفواتير والبحث.
- 10 اختبارات PHP ناجحة لإعادة تعيين كلمة المرور، وتشفير الرسائل، وإرجاع مخزون الطلب الملغي، وحفظ الفواتير التاريخية.
- 9 اختبارات JavaScript ناجحة، منها محاكاة فشل الكتالوج مع نجاح الطلبات والفاتورة، وفشل المفضلة الاختياري، وحفظ وجهة الرجوع، وترجمة تفاصيل الفاتورة.
- فحص بنية 20 صفحة HTML والروابط المحلية والجداول والصور، مع فحص صياغة ملفات PHP وJavaScript.

نتائج التفاصيل: revision-api-results.json وfrontend-test-results.json وrevision-browser-results.json.

هذه اختبارات محلية في المتصفح المتاح، ولا تعني اختبار كل إصدار متصفح أو كل جهاز فعلي. البريد الفعلي يحتاج إعداد SMTP؛ صور المجموعة رسومات SVG أصلية وليست صور منتجات تجارية.

- إتمام طلب من واجهة الدفع بالإنجليزية نجح (ST-000007 في قاعدة الاختبار). تم تثبيت قيم شركات الشحن بالعربية داخل value مع ترجمة أسماء العرض فقط.
- فُكت الحزمة المحدثة وشُغلت على المنفذ 8091 وقاعدة مستقلة؛ نجح الإعداد الأول ثم اختبارات API الـ17 واختبارات الواجهة.
