# ابدأ من هنا — STOR HTML + PHP

هذه النسخة المصححة: 20 ملف HTML مستقل، وتنسيقات CSS في مجلد مستقل، وJavaScript للتفاعل، وPHP للعمليات وقاعدة MySQL. لا توجد صفحة PHP تجمع صفحات المتجر كلها.

> إذا عندك نسخة سابقة وحسابات محفوظة: اتبع UPDATE.md أولًا، ولا تعِد استيراد SQL إلى القاعدة القديمة.

## التشغيل على Windows

1. فك ضغط الحزمة كاملة. لا تنقل public وحده، ولا تفتح PHP بالنقر المزدوج.
2. شغّل MySQL على جهازك. تحتاج MySQL 8.0.16 أو أحدث، ومستخدمًا يملك إنشاء قاعدة وجداول أو صلاحية على قاعدة فارغة.
3. شغّل `START-WINDOWS.cmd` بالنقر المزدوج. يحتاج PHP 8.2+ مع PDO MySQL وmbstring وOpenSSL وArgon2id. يبحث عن PHP في PATH أو XAMPP أو runtime محلي. احتفظ بنافذة الخادم مفتوحة.
4. افتح **http://127.0.0.1:8088/**. عند أول تشغيل يفتح `setup.php`.
5. أدخل بيانات MySQL المحلية واختر اسم قاعدة جديدة/فارغة. أنشئ اسم دخول وبريدًا وكلمة مرور خاصة بالأدمن. لا توجد كلمة مرور أدمن افتراضية.
6. بعد نجاح الإعداد يُفتح `index.html` تلقائيًا وتُغلق صفحة الإعداد. دخول الإدارة من رابط التذييل أو **http://127.0.0.1:8088/dashboard.php**.

إذا لم يوجد PHP، ثبّت PHP من مصدره الرسمي أو استعمل PHP المتوفر مع XAMPP مع خادم MySQL المطلوب. لا تحتاج Node.js أو npm. مكتبة PHPMailer مرفقة في vendor.

## أمر التشغيل البديل

من جذر المشروع، شغّل:

```powershell
php -S 127.0.0.1:8088 -t public router.php
```

إذا كان PHP موجودًا في XAMPP فقط:

```powershell
C:\xampp\php\php.exe -S 127.0.0.1:8088 -t public router.php
```

إذا كان المنفذ مشغولًا، أغلق نافذة PHP السابقة لهذا المشروع أو اختر منفذًا آخر. عند تغيير عنوان موقع مُعد مسبقًا، غيّر origin في config/config.local.php ليتطابق مع عنوان المتصفح؛ localhost و127.0.0.1 ليسا نفس الأصل.

## مهم لمعرفة ما يعمل

ملفات HTML تحتوي محتواها ويمكن قراءة أكوادها مباشرة. التشغيل الكامل للحسابات والمنتجات والطلبات يتطلب PHP وMySQL، ولا يعمل باستخدام Live Server فقط. عند غياب الخادم تبقى الواجهة وتعرض رابط الإعداد بدل إظهار صفحة فارغة أو حسابات وهمية.

قاعدة الموقع وملف config/config.local.php ينشئهما معالج الإعداد محليًا، ولا تحتوي الحزمة على كلمات مرورك أو حساباتك القديمة. لم نعدّل المتجر المنشور في Netlify أو قاعدة Aiven.

معالج الإعداد مخصص لـlocalhost ويغلق بعد نجاحه. لاستضافة عامة اجعل DocumentRoot هو public فقط، واستعمل حساب MySQL محدودًا، وجهّز الإعدادات من الطرفية أو احذف setup.php بعد التجهيز.

التفاصيل الإضافية في docs/SETUP.md، ومطابقة المتطلبات في docs/REQUIREMENTS.md، ونتائج الاختبارات في docs/VERIFICATION.md.
